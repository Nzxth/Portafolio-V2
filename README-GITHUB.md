# aleeushii — Portafolio para GitHub Pages

Este paquete contiene una página estática lista para publicar, sin instalación de Node.js ni compilación.

## Publicación

1. En GitHub, crea un repositorio público, por ejemplo `aleeushii-portfolio`.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio: `index.html`, `refinement.css`, `refinement.js` y la carpeta `assets`.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main`, carpeta `/(root)` y guarda.
6. Espera a que GitHub indique que la página está publicada. La dirección será `https://TU-USUARIO.github.io/aleeushii-portfolio/` si usas ese nombre de repositorio.

## Antes de compartir

- Revisa en móvil y escritorio la animación de bienvenida y la transición del papel.
- El formulario de contacto **solo copia una solicitud al portapapeles**: no envía mensajes. Para recibir pedidos directamente, añade un enlace real a tu Instagram, WhatsApp o correo.
- Las imágenes de los proyectos son recreaciones ilustrativas; sustituye las que quieras por capturas de trabajos reales.
- Algunos dispositivos pueden simplificar efectos si tienen activada la opción de reducir movimiento.

No necesitas poner `dist` como subcarpeta en el repositorio; sube sus archivos a la raíz.
